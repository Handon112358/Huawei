那我们来反思一下如何：首先，我遇到了这样的一个问题，那就是我试图构建的训练环境，按照iplanner的paper，是一个较为静态的背景，他不容易迁移到动态的问题中去。

为什么呢，因为涉及到了一个静态的ESDF cost map,这个map是后续的东西能够成功运行的保证，但是他很难说能一下子就搞好到动态去。他的构建原理是基于重建，要把像素点映射到3D的空间里面去然后使用高斯核函数来平滑一下，后面伴随一个下采样，我现在的问题是认为：下采样这一步，会造成动态物体的消失。这个是需要理论和实验验证的。我先进行一下理论验证吧。

看起来下采样并不是我想象的那样，因为下采样是一个均匀化的过程，他会把点云进行平均化，类似一个卷积核的操作，那么此时我认为动态物体不一定会消失，所以我需要进一步的进行验证，我要询问，这个下采样是不是类似于卷积操作，或者说，我直接询问，下采样对于动态物体会有什么效果。这个目前好像就还行，我觉得大不了你从头开始搞就是了。反正只要有一个静态的路径目标就OK，然后你开始随着动态的障碍开始避开障碍物，看看怎么搞算法来模拟那个过程。

这样的话，其实我们就不需要动态的ESDF了，而是仅仅需要把对于动态物体的识别和知识搞到flow matching里面去。但是问题是在于，你能不能走对，可以尝试一下。
